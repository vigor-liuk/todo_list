# 小日 · 待办事项

使用 React + TypeScript + Vite 开发的中文待办提醒工具。

## Windows 独立应用（1.0.1）

运行 `release/LittleDay-Setup-1.0.1.exe` 安装，随后双击桌面「小日」图标即可使用。
支持 Windows 10/11 x64；使用者无需安装 Node.js、登录 Codex、启动终端或打开浏览器。
首版无需账号、无需服务器，任务管理可以断网使用。安装包尚未使用商业代码签名证书签名。

- 点击窗口关闭按钮会隐藏到系统托盘，后台继续提醒。单击托盘图标或右键选择「打开小日」恢复窗口；右键「退出」彻底结束程序。
- 不自动开机启动。退出、关机或设备休眠期间不保证通知；重新打开或唤醒时检查错过的任务。
- Windows 通知设置、勿扰模式可能阻止系统横幅；应用内「查看提醒」仍记录本次运行的到期任务。
- 已提醒状态在通知投递前保存，避免重启重复提醒。极端情况下若刚保存就崩溃，可能不再投递该条系统通知；任务仍保留。
- 桌面版首次使用为空清单。网页版保留原有示例任务。

### 数据、备份与迁移

手动导出的“小日任务-日期.json”与内部自动保存文件不同。网页版导出由浏览器处理，通常保存在“下载”目录，可在下载列表查看实际位置；桌面版导出可选择文件夹，并提示保存路径。导出任务不会创建“导入前备份”，首次确认导入才创建。

桌面任务保存在 `%APPDATA%\LittleDay\tasks.json`，格式为 `{ "version": 1, "tasks": [...] }`。
文件先写临时文件并刷盘，再原子替换；写入失败不会更新界面中的任务状态。
无法读取或校验原文件时，程序会报错并保留原文件，不会默默覆盖成空数据。

1. 在原来使用的浏览器、相同站点地址打开更新后的网页版，点击「导出任务」。不同端口或浏览器的本地数据并不互通。
2. 打开桌面小日，点击「导入任务」，选择导出的 JSON 文件。
3. 确认后合并清单：保留所有现有任务，只补充不同编号的新任务；相同编号保留本机版本，重复导入不会重复添加。桌面导入前自动保存一份 `tasks.json.before-import.bak`，网页版保存在 `little-day-tasks-v1-before-import` 存储项中。

导入支持上述版本文件和原始任务数组，迁移旧「工作/学习」分类，拒绝无效字段、重复编号、不存在的日期和超过 10 MB 的文件。最多 10000 条任务。
自动备份只保留最近一次导入前的数据；重要数据请主动导出到其他位置。
点击“数据与备份”可查看实际数据和备份位置；桌面版可直接“打开数据文件夹”。两种版本都可“导出上次备份”，再通过“导入任务”合并找回缺失的任务。也可将 `.bak` 复制为 `.json` 后导入。损坏数据导致无法启动时，退出程序后先另存原文件，再用有效备份恢复 `tasks.json`。

### 升级与卸载

先从托盘退出小日，再运行新版安装包，选择原安装目录。任务目录独立于安装目录，升级和卸载均不主动删除任务。
首版不包含自动更新。需要清除个人数据时，请在退出应用并导出备份后自行处理上述数据目录。

### 开发、测试和打包

```bash
npm ci
npm run desktop
npm run test:unit
npm run test:desktop
npm run dist:win
npm run test:packaged
```

`desktop` 构建并加载本地资源，不启动开发服务器。`dist:win` 生成 x64 NSIS 安装包。
首次安装构建依赖时需要联网下载 Electron 和打包工具；最终安装包包含运行所需环境。
`test:packaged` 在独立临时数据目录运行打包后的 exe，并移除子进程 PATH 中的 Node.js 路径，检查本地界面和任务保存。也可运行 `node scripts/verify-packaged.mjs "安装目录/LittleDay.exe"` 检查安装结果。
若 GitHub 下载超时，可为当前构建终端设置 `ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/`；工具仍按内置校验值验证下载文件。`dist:win` 复用已安装的 Electron 运行时，避免再次下载。
应用图标已经随仓库提供，可在 Windows 上运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/create-icon.ps1` 重新生成。

桌面界面关闭 Node 集成并启用沙箱、上下文隔离和内容安全策略，使用专用本地协议加载资源。
预加载接口仅提供任务读取、受校验的任务操作、导出和状态订阅；存储与后台提醒统一由主进程处理。
`shared/tasks.mjs` 是网页和桌面共用的数据校验、迁移、操作和提醒规则；手机和云同步可以后续增加独立适配器。
本阶段不包含账号、云服务器、Android 安装包或多端同步。

## 本地运行

```bash
npm install
npm run dev
```

打开终端显示的本地地址（默认 http://localhost:5173）。

## 功能

- 新增、编辑、删除、完成与恢复任务
- 课外、个人、课内、生活分类（自动迁移旧分类）；高、中、低优先级
- 今天、全部任务、即将到来、已完成视图
- 搜索、状态筛选、时间与优先级排序
- 月历日期筛选、今日完成进度
- 到期页面提醒，以及用户授权后的浏览器系统通知
- localStorage 本地持久化，适配桌面和手机

首次使用提供可编辑、可删除的示例任务。无日期任务在“全部任务”和对应分类中查看。

## 提醒范围（网页版）

纯前端版本需要保持页面打开，浏览器后台节流或设备休眠可能延迟提醒；重新进入页面时会检查已到期任务。关闭页面期间不发送推送。已提醒标记会保存，修改到期时间会重新启用提醒。提醒面板记录仅保留在当前页面会话。数据保存在当前浏览器和站点下，不跨设备同步。

## 验证与构建

```bash
npm run lint
npm run build
npm test
```

浏览器测试使用本机 Google Chrome，由 Playwright 自动启动开发服务器，覆盖任务 CRUD、持久化、筛选、提醒去重及响应式布局。生产文件输出到 `dist/`，可用 `npm run preview` 预览。


## 每日激励与手动时间

每日激励从一言哲学接口获取，优先展示包含励志主题的句子，并显示来源链接。按本机日期缓存，一天内刷新页面不重复请求，页面跨午夜自动更新；网络异常、接口超时或返回内容不符合主题时，使用按日期轮换的小日精选语录。接口只请求语录，不发送任务数据。接口说明：https://developer.hitokoto.cn/sentence/

时间编辑器提供“日历选择”和“手动输入”两个入口。手动输入各字段时不自动补零；点击“确认时间”或保存任务时，校验真实日期、闰年和小时分钟范围，年月日统一为 4、2、2 位。年份必须完整输入 4 位。点击“不设提醒”可清空时间。
