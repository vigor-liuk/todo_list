# 小日 · 待办事项

使用 React + TypeScript + Vite 开发的中文待办提醒工具。

## Windows 独立应用（1.0.3）

从 [GitHub Releases 下载 LittleDay-Setup-1.0.3.exe](https://github.com/vigor-liuk/todo_list/releases/tag/v1.0.3)，运行安装包后双击桌面「小日」图标即可使用。本地构建的安装包位于 `release/LittleDay-Setup-1.0.3.exe`。
支持 Windows 10/11 x64；使用者无需安装 Node.js、登录 Codex、启动终端或打开浏览器。
1.0.3 同步最新网页版功能，包括每日推荐、任务实际时间记录、每日时间回顾，以及每天、每周和每月重复任务。
首版无需账号、无需服务器，任务管理可以断网使用。安装包尚未使用商业代码签名证书签名。

- 点击窗口关闭按钮会隐藏到系统托盘，后台继续提醒。单击托盘图标或右键选择「打开小日」恢复窗口；右键「退出」彻底结束程序。
- 不自动开机启动。退出、关机或设备休眠期间不保证通知；重新打开或唤醒时检查错过的任务。
- Windows 通知设置、勿扰模式可能阻止系统横幅；应用内「查看提醒」仍记录本次运行的到期任务。
- 已提醒状态在通知投递前保存，避免重启重复提醒。极端情况下若刚保存就崩溃，可能不再投递该条系统通知；任务仍保留。
- 桌面版首次使用为空清单。网页版保留原有示例任务。

### 数据、备份与迁移

手动导出的“小日任务-日期.json”与内部自动保存文件不同。网页版导出由浏览器处理，通常保存在“下载”目录，可在下载列表查看实际位置；桌面版导出可选择文件夹，并提示保存路径。导出任务不会创建“导入前备份”，首次确认导入才创建。

桌面任务保存在 `%APPDATA%\LittleDay\tasks.json`，格式为 `{ "version": 1, "tasks": [...] }`。
文件先写临时文件并刷盘，再原子替换；写入失败不会更新界面中的任务状态。
无法读取或校验原文件时，程序会报错并保留原文件，不会默默覆盖成空数据。

1. 在原来使用的浏览器、相同站点地址打开更新后的网页版，点击「导出任务」。不同端口或浏览器的本地数据并不互通。
2. 打开桌面小日，点击「导入任务」，选择导出的 JSON 文件。
3. 确认后合并清单：保留所有现有任务，只补充不同编号的新任务；相同编号保留本机版本，重复导入不会重复添加。桌面导入前自动保存一份 `tasks.json.before-import.bak`，网页版保存在 `little-day-tasks-v1-before-import` 存储项中。

导入支持上述版本文件和原始任务数组，迁移旧「工作/学习」分类，拒绝无效字段、重复编号、不存在的日期和超过 10 MB 的文件。最多 10000 条任务。
自动备份只保留最近一次导入前的数据；重要数据请主动导出到其他位置。
点击“数据与备份”可查看实际数据和备份位置；桌面版可直接“打开数据文件夹”。两种版本都可“导出上次备份”，再通过“导入任务”合并找回缺失的任务。也可将 `.bak` 复制为 `.json` 后导入。损坏数据导致无法启动时，退出程序后先另存原文件，再用有效备份恢复 `tasks.json`。

### 升级与卸载

先从托盘退出小日，再运行新版安装包，选择原安装目录。任务目录独立于安装目录，升级和卸载均不主动删除任务。
首版不包含自动更新。需要清除个人数据时，请在退出应用并导出备份后自行处理上述数据目录。

### 开发、测试和打包

```bash
npm ci
npm run desktop
npm run test:unit
npm run test:desktop
npm run dist:win
npm run test:packaged
```

`desktop` 构建并加载本地资源，不启动开发服务器。`dist:win` 生成 x64 NSIS 安装包。
`release/`、`dist/`、`node_modules/` 均为本地生成目录，不纳入 Git 仓库；Windows 安装包作为 GitHub Release 附件下载。克隆源码后运行 `npm ci` 和 `npm run dist:win` 也可在本地生成安装包。
首次安装构建依赖时需要联网下载 Electron 和打包工具；最终安装包包含运行所需环境。
`test:packaged` 在独立临时数据目录运行打包后的 exe，并移除子进程 PATH 中的 Node.js 路径，检查本地界面和任务保存。也可运行 `node scripts/verify-packaged.mjs "安装目录/LittleDay.exe"` 检查安装结果。
若 GitHub 下载超时，可为当前构建终端设置 `ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/`；工具仍按内置校验值验证下载文件。`dist:win` 复用已安装的 Electron 运行时，避免再次下载。
应用图标已经随仓库提供，可在 Windows 上运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/create-icon.ps1` 重新生成。

桌面界面关闭 Node 集成并启用沙箱、上下文隔离和内容安全策略，使用专用本地协议加载资源。
预加载接口仅提供任务读取、受校验的任务操作、导出和状态订阅；存储与后台提醒统一由主进程处理。
`shared/tasks.mjs` 是网页和桌面共用的数据校验、迁移、操作和提醒规则；手机和云同步可以后续增加独立适配器。
本阶段不包含账号、云服务器、Android 安装包或多端同步。

## 功能

- 新增、编辑、删除、完成与恢复任务
- 周期任务：在任务编辑器选择每天、每周或每月，设置开始日期、提醒时间和可选目标分钟数；全部任务始终只显示一条，不新增侧栏入口
- 任务开始 / 结束时间、实际用时、按日期查看时间回顾，并对照原计划提醒时间
- 课外、个人、课内、生活分类（自动迁移旧分类）；高、中、低优先级
- 今天、全部任务、即将到来、已完成视图
- 搜索、状态筛选、时间与优先级排序
- 月历日期筛选、今日完成进度
- 到期页面提醒，以及用户授权后的浏览器系统通知
- localStorage 本地持久化，适配桌面和手机
- 每日推荐：按兴趣、关注方向、任务分类与待办负担推荐小任务，支持联网参考资料、跳过与加入今日清单

周期任务按本机日期与时间执行，各周期独立保存完成状态、提醒状态和实际起止时间，支持导入导出和时间回顾。每周沿用开始日期对应的星期；每月沿用开始日期中的日，短月落在月末。完成后保留本期完成状态，到下一周期自动恢复待办；跨午夜仍在计时的任务可先结束本次执行。程序再次打开时只提醒当前周期，不批量补发错过的周期。选择“不重复”会转为当前这次的普通任务，并移除周期记录。

首次使用提供可编辑、可删除的示例任务。无日期任务在“全部任务”和对应分类中查看。

### 任务时间记录与每日回顾

在每个任务右侧“编辑”“删除”图标下方点击“开始”记录实际开始时间，点击“结束并完成”或完成复选框记录完成时间。关闭页面、退出应用或重启后，起止记录仍保留；进行中显示从开始到当前的连续经过时间（包括应用关闭期间），本版不包含暂停和分段计时。

图标按钮在鼠标持续悬停时显示作用提示。点击侧栏“时间回顾”或清单上方“查看今日时间回顾”，可查看带 00:00–24:00 整点刻度的全天横向时间轴：紫色横条表示已完成时段，绿色横条表示进行中时段，菱形标出原定提醒，圆点表示仅记录完成时刻。每行一个任务，可对照重叠时段；未执行的当天安排也显示提醒标记。点击任务或图形查看详情、修改记录，窄屏下可左右滑动，任务名称固定在左侧。实际记录按开始时间排序，不受任务提醒日期限制；跨天任务在涉及的每一天显示，当天统计只累计当天的部分。多个任务同时进行时分别累计，合计可能超过一天的时长。完成数量按实际完成日期统计。

编辑任务时展开“实际执行时间 · 补录 / 修改”，可补填或调整本机时区的开始和完成时间。完成时间不能早于开始时间，补录时间不能在未来；填写完成时间自动标记完成，只填开始时间表示进行中。取消完成会清空本次起止记录，便于重新开始；删除任务也删除其时间记录。

旧任务保持原状，不推测历史时间。未点击开始而直接完成的任务只记录完成时刻，不计入用时。新增时间字段随本地保存、导入、导出与备份一起保留，继续兼容旧版任务文件；旧版应用不了解这些字段，含时间记录的数据请用新版应用管理。

## 提醒范围（网页版）

纯前端版本需要保持页面打开，浏览器后台节流或设备休眠可能延迟提醒；重新进入页面时会检查已到期任务。关闭页面期间不发送推送。已提醒标记会保存，修改到期时间会重新启用提醒。提醒面板记录仅保留在当前页面会话。数据保存在当前浏览器和站点下，不跨设备同步。

## 每日激励与手动时间

每日激励从一言哲学接口获取，优先展示包含励志主题的句子，并显示来源链接。按本机日期缓存，一天内刷新页面不重复请求，页面跨午夜自动更新；网络异常、接口超时或返回内容不符合主题时，使用按日期轮换的小日精选语录。接口只请求语录，不发送任务数据。接口说明：https://developer.hitokoto.cn/sentence/

时间编辑器提供“日历选择”和“手动输入”两个入口。手动输入各字段时不自动补零；点击“确认时间”或保存任务时，校验真实日期、闰年和小时分钟范围，年月日统一为 4、2、2 位。年份必须完整输入 4 位。点击“不设提醒”可清空时间。

## 每日任务推荐

首次进入应用、且尚未保存过推荐偏好时，会自动显示兴趣引导。选择后点击“选好了，开始使用”，或点击“暂时跳过”直接进入；关闭按钮、Escape 和点击弹窗外也按跳过处理。完成或跳过后，刷新、重启和跨日都不会再次自动弹出。跳过不保存尚未提交的选择，使用默认探索建议；已有有效偏好的老用户不会重复看到引导。引导结束前不发起推荐资料搜索，保存失败时保留弹窗并提示重试。

后续可在任意任务页面通过右上角“设置 → 推荐偏好”修改，也保留每日推荐卡片上的“推荐偏好”入口。首次引导状态保存在当前浏览器或桌面应用的本地存储中；更换浏览器、站点地址或清除应用数据后会重新引导。

在“今天”清单下方查看“每日推荐”。每天提供 5–10 个候选，用户可以只选一两个，也可以全部不选；候选不会自动变成待办。默认候选数量为 8，可在“推荐偏好”中修改，并设置每日可用时间为 15/30/60 分钟。原来设置 3 或 4 个的用户自动迁移为 8 个，原 5 或 6 个的设置保持不变。

兴趣领域仍有“感兴趣 / 未明确 / 不感兴趣”三种态度。存在感兴趣领域时，约八成候选分配给这些领域，其余 1–2 个用于探索未明确领域；只有感兴趣领域时全部从中推荐。没有标记任何兴趣时提供 5 个探索候选，全部不感兴趣时暂停推荐和资料搜索。每天轮换小任务，并优先展示最近 7 天没有接受过的通用内容。同一领域也能提供 10 个不同候选，已排除领域不会因任务历史或联网资料重新加入。旧版勾选和取消勾选分别兼容为感兴趣和不感兴趣。

兴趣关键词优先用于学习与创作，常用任务分类只在感兴趣领域内参与排序，未明确领域按日期轮换。可用时间用来安排一般候选的预计用时（按选两件估算），并不是要求完成整个推荐池；待办较多时缩短一般候选用时。递进目标保留用户之前选择的尺度，接受前可自行减量。推荐是本地规则生成，不调用大模型。

默认每天通过中文维基百科 Action API 搜索推荐主题与兴趣，学习建议结合搜索结果，其余建议附延伸阅读链接。此功能是公开知识检索，不是全网新闻、实时活动或位置推荐。请求去重、超时 6.5 秒；服务不可达、无结果或响应异常时明确显示本地建议。搜索接口说明：[MediaWiki Search](https://www.mediawiki.org/wiki/API:Search)。

联网只发送主题和手动填写的兴趣，不发送已有任务标题、备注、完成记录或其他个人资料；也可在偏好中关闭联网。任务分类与待办数量只在本地分析。桌面版允许访问该固定服务，并在系统浏览器中打开对应百科资料。

按本机日期自动更新：打开应用或页面跨午夜时生成当天建议，睡眠唤醒后在界面恢复时检查；退出应用或关闭网页期间不执行搜索。同一天刷新使用缓存，任务变化不会不断重排当天建议；修改偏好会重新生成。网络失败的本地结果也缓存到当天。联网功能需要能访问中文维基百科的网络环境。

“今天跳过”会保存当天选择，可恢复。点击“选择并调整”，可以修改标题、数值目标、备注、预计用时和提醒时间；点击“确认加入计划”才创建任务。“再想想”不保存任何接受记录。同一建议和仍在清单中的同名任务不会重复添加；保存失败不标记为已选择。默认提醒为当天 23:59，可在确认前清空或调整。

### 递进目标和选择记录

跑步、阅读、整理、创作、问候与日记各有一个可选的递进候选。第一次从小目标开始（例如跑步 1 公里）；后续优先沿用最近实际接受或修改的数值。只有最近两条相同目标的任务已在两个不同日期完成，且完成日期早于今天，才建议小幅提升（跑步增加 0.2 公里，阅读增加 5 分钟等，并设有建议上限）。仅展示、跳过、接受但未完成，都不会增加目标。用户随时可以减量，最近一次减量会成为新的参考。进阶始终只是候选，不会直接修改已有任务。

“选择与调整记录”可查看原推荐、首次接受的版本、当前任务和最近 20 次内容/目标/用时修改。记录作为任务的可选 `recommendation` 字段与任务一起校验、原子保存、导出和导入，网页和桌面共用规则。后续在任务编辑器中可修改数值目标和预计用时；修改已完成任务的目标量会恢复为未完成，避免把新目标误认为已经完成。自由改写标题会保留文字记录，但该记录不再用于自动数值进阶；系统不会猜测改写后的运动或数量含义。

选择记录仅保存在本机，不上传到搜索服务。删除任务也会删除附带记录，重要记录请随任务导出备份；旧任务没有选择记录时不会推测补写。偏好、当天候选缓存与跳过记录仍单独保存在 localStorage 中，不包含在任务 JSON 备份里。更换日期后，新一批候选会读取最新的选择与完成记录；当天已缓存的候选保持稳定。
